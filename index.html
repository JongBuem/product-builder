통계 검증

확률 계산 방법 설명

로또 6/45의 수학적 사실

로또 6/45의 1등 당첨 확률은 정확히 1/8,145,060입니다. 각 회차는 독립 시행이므로, 과거 데이터는 다음 회차의 번호를 예측하는 데 수학적으로 아무런 도움이 되지 않습니다. N회차 기준 각 번호의 기대 출현 횟수는 N×6/45이며, 실제 빈도 편차는 통계적 노이즈 범위 안에 들어옵니다. "핫 넘버"는 신호가 아니라 노이즈입니다.

과거 데이터 기반 생성

업로드된 과거 당첨번호의 출현 빈도에 비례하여 가중치를 부여한 뒤 무작위 추출합니다. 당첨 확률은 순수 무작위와 동일합니다.

궁극의 번호 생성

빈도 점수(35%) + 최신성 점수(40%) + 미출현 점수(25%)를 합산하여 가중 랜덤 추출합니다. 단, 최신성 점수(최근 출현 우대)와 미출현 점수(장기 미출현 우대)는 서로 반대 방향으로 작용하여 상당 부분 상쇄됩니다. 당첨 확률은 무작위와 동일합니다.

기대 수령액 최적화 — 유일하게 수학적 근거가 있는 기능

1등은 분배식(pari-mutuel) 구조입니다. 당첨 확률은 어떤 방법으로도 바꿀 수 없지만, 같은 조합을 고른 사람이 적으면 수령액이 올라갑니다. 이 기능의 수학적 근거는 확률 향상이 아니라 분배 인원 감소입니다. 생일 숫자 편중, 연속 번호, 등차수열, 마킹지 패턴 등 많은 사람이 고르는 조합 특성을 회피합니다. "이 필터는 당첨 확률을 높이지 않습니다"
